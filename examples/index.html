preSintaxis.js v1.0.2

Librería minimalista de resaltado de sintaxis basado en categorías semánticas para HTML estático. Sin dependencias, sin build step y ultra ligera (~2 KB gzip).

🚀 Instalación

CDN (Recomendado para empezar)

Simplemente agrega el core de la librería y el lenguaje que necesites en tu HTML:

<!-- 1. Core de la librería -->
<script src="https://cdn.jsdelivr.net/gh/TU-USUARIO/presintaxis@v1.0.2/dist/preSintaxis.min.js"></script>

<!-- 2. Lenguaje (ejemplo: JavaScript) -->
<script src="https://cdn.jsdelivr.net/gh/TU-USUARIO/presintaxis@v1.0.2/dist/lang/JavaScript.js"></script>

Descarga directa o NPM

Descarga el archivo dist/preSintaxis.min.js y añádelo a tu proyecto, o instálalo vía NPM:

npm install presintaxis

🛠️ Uso Básico

El núcleo (Core) incluye las funciones esenciales: tokenización, encabezados, botón de copiar y numeración de líneas. La librería se auto-inicializa al cargar la página.

<pre data-encabezado="app.js" data-ajuste="{copiar:'true', lineas:'true'}">
  <code data-sintaxis="javascript">
const saludo = "Hola Mundo";
console.log(saludo);
  </code>
</pre>

🧩 Plugins Opcionales

Para mantener la librería extremadamente ligera, las funciones avanzadas se cargan como plugins independientes. Solo debes cargar los que necesites después del Core.

1. Temas (temas.js)

Añade temas de color predefinidos listos para usar (Dracula, Nord, GitHub Light).

<script src="dist/plugins/temas.js"></script>
<script>
  // Aplicar un tema (los estilos se inyectan dinámicamente en el core)
  preSintaxisTemas.aplicar('dracula');
</script>

2. Scroll Automático (scroll.js)

Añade una barra de desplazamiento vertical si el bloque de código es muy largo.

<script src="dist/plugins/scroll.js"></script>

<!-- Activa el scroll a partir de 20 líneas -->
<pre data-ajuste="{maxlineas:'20', altura:'30rem'}">...</pre>

3. Descargar Código (descargar.js)

Añade un botón para descargar el bloque de código como archivo de texto.

<script src="dist/plugins/descargar.js"></script>
<pre data-encabezado="script.js" data-ajuste="{descargar:'true'}">...</pre>

4. Resaltar Líneas (resaltar.js)

Permite resaltar líneas específicas o rangos con un color de fondo.

<script src="dist/plugins/resaltar.js"></script>

<!-- Resalta las líneas 2, 3 y 4 -->
<pre data-ajuste="{resaltar:'2-4'}">...</pre>

⚙️ Atributos HTML

En la etiqueta <pre>

Atributo Descripción
data-encabezado Nombre del archivo. Se muestra como header del bloque.
data-ajuste Objeto con la configuración del bloque (ver tabla abajo).

En la etiqueta <code>

Atributo Descripción
data-sintaxis Lenguaje del código: javascript, python, css, html, rust, o uno registrado con registrarSintaxis().

Ajustes (data-ajuste)

Se pasan como objeto literal dentro del atributo: data-ajuste="{copiar:'true', lineas:'true'}"

Clave Valores Default Descripción
copiar 'true' / 'false' false Añade botón para copiar el código al portapapeles.
lineas 'true' / 'false' false Muestra numeración de líneas.
resaltar '1', '2-4', '1,3-5' — Resalta líneas específicas (requiere plugin).
descargar 'true' / 'false' false Añade botón para descargar el código (requiere plugin).
maxlineas '20' / '0' 20 Umbral de líneas para activar scroll (requiere plugin).
altura '30rem' 24rem Altura máxima del área scrollable (requiere plugin).

🔌 API de JavaScript

preSintaxis.registrarSintaxis(lenguaje, reglas)

Registra un lenguaje nuevo o redefine uno existente.

preSintaxis.registrarSintaxis('rust', [
  { tipo: 'comentario',  regex: /\/\/[^\n]*/ },
  { tipo: 'valor',       regex: /"(?:[^"\\]|\\.)*"/ },
  { tipo: 'palabra',     regex: /\b(?:fn|let|mut|const|struct|impl|trait|pub|use|mod|match|if|else|for|while|loop|return|self|as|where|async|await|dyn|in)\b/ },
  { tipo: 'tipo',        regex: /\b(?:i32|i64|u32|u64|f32|f64|bool|char|str|String)\b/ },
  { tipo: 'valor',       regex: /\b\d+(?:\.\d+)?\b/ },
  { tipo: 'delimitador', regex: /[(){}\[\];,.:#]/ },
  { tipo: 'operador',    regex: /[+\-*/%=<>!&|^~?]+/ },
  { tipo: 'identificador', regex: /\b[A-Za-z_]\w*\b/ }
]);
Reglas importantes: El orden importa. Las reglas se aplican en orden declarado. Pon primero las de mayor prioridad (comentarios antes que strings, strings antes que palabras clave).

preSintaxis.init(root?)

Procesa todos los bloques <pre> no procesados dentro de root (por defecto document).

preSintaxis.init(document.getElementById('mi-seccion'));

preSintaxis.destruir(selector?)

Revierte los bloques a su estado original. Útil para SPAs.

preSintaxis.destruir('#mi-seccion pre');

preSintaxis.version

Devuelve la versión actual como string.

console.log(preSintaxis.version); // "1.0.2"

🎨 Tipos de Token (Categorías Semánticas)

A diferencia de otros resaltadores que dividen el código en tokens genéricos (como clave o texto), preSintaxis analiza el código utilizando categorías semánticas reales:

  • .ps-palabra — Palabras reservadas (if, return, const)
  • .ps-identificador — Variables, funciones, clases
  • .ps-operador — Símbolos de asignación y lógicos
  • .ps-delimitador — Paréntesis, llaves, corchetes, puntos y comas
  • .ps-tipo — Tipos de datos (string, int, bool)
  • .ps-valor — Strings y números literales
  • .ps-comentario — Textos explicativos ignorados por la máquina

🖌️ Personalización de Colores (CSS)

La librería inyecta sus estilos en un bloque <style id="ps-estilos">. Puedes sobrescribir los colores modificando las variables CSS en tu propio archivo de estilos:

  
    :root {
  --ps-contenido: #111827; /* Fondo del código */
  --ps-texto: #e5e7eb;     /* Texto por defecto */
  
  /* Colores semánticos */
  --ps-palabra: #f472b6;       
  --ps-identificador: #e5e7eb; 
  --ps-operador: #94a3b8;      
  --ps-delimitador: #6b7280;   
  --ps-tipo: #38bdf8;          
  --ps-valor: #a3e635;         
  --ps-comentario: #6b7280;    
}

⚠️ Limitaciones

  • No es un parser real. Es un tokenizador de expresiones regulares aplicadas en orden. Lenguajes con contexto complejo (JSX, HTML-in-JS, plantillas anidadas) se colorean de forma aproximada.
  • Rendimiento: Para bloques de más de 500 líneas, el motor de regex puede ralentizarse. Se recomienda usar el plugin de scroll.
  • Detección de lenguaje: Requiere data-sintaxis explícito en la etiqueta <code>.

Notas de implementación

Si se escapara el HTML antes de tokenizar (convirtiendo < en &lt;), las regex que buscan strings o comentarios fallarían. Al tokenizar sobre texto crudo y escapar cada token individualmente, el coloreado es correcto incluso cuando hay HTML dentro de strings.

Los estilos base se inyectan en el <style id="ps-estilos"> usando un contenedor .ps-contenido que evita los problemas clásicos de saltos de línea y márgenes asimétricos en <pre> y <code>.
